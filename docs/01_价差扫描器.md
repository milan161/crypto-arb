## 2. 净价差公式

```
毛价差 = (卖出所 bid − 买入所 ask) ÷ 买入所 ask
净价差 = 毛价差 − 买入所 taker 费 − 卖出所 taker 费 − 滑点缓冲
```

- 在 ask 低的一边**买**，在 bid 高的一边**卖**，用的是对手价（吃单），不是 last。
- 四项少一项，结论都会失真。

## 4. 今天观察到的三件事

**① 成本是价差的一百多倍。**
BTC 毛价差只有 0.003% 左右，成本 0.3%～0.4%。主流币在大交易所之间做纯现货搬砖，做一次亏一次。这就是计划书里"不做纯现货跨所搬砖"的原因。

**② 费率每家不同，而且 ccxt 给的是默认档位。**
ccxt 内置费率：okx 0.15%、bybit 0.10%、gate 0.20%。换交易所，成本就从 0.30% 变成 0.40%。实际账户有 VIP 档位、平台币抵扣，通常更低。后面接入 API Key 后改用 `fetch_trading_fees` 读真实费率。

**③ 毛价差经常正好是 0.0000%。**
SOL 价格最小变动 0.01，72.61 跳一档就是 0.014%，比两所真实价差还大，所以两边经常报出一模一样的价格。这叫**价格精度（tick size）**，阶段 2 下单时会用到 `price_to_precision`。

## 5. 报错排查：403 和超时是两回事

| 报错 | 原文特征 | 原因 | 怎么办 |
|---|---|---|---|
| 403 Forbidden | `block access from your country` | 交易所按 IP 地区拦截（如 Bybit 封美国） | 换非美国节点，或换交易所 |
| RequestTimeout | `Read timed out` | 代理节点慢或刚切换不稳定 | 测速换节点，切换后等 10 秒 |
| No module named 'dotenv' | — | 新窗口没激活 venv | 双击 `start.bat`，或 `.venv\Scripts\activate` |

注意：ccxt 把那次 403 归成了 `RateLimitExceeded`（限频），这是分类不准。**看报错要看原始响应正文，别只看异常类名。**

用 curl 快速判断节点好坏（`time_total` 在 1～2 秒以内为合格）：

```powershell
curl.exe -x http://127.0.0.1:10808 -m 10 -s -o NUL -w "okx %{http_code} %{time_total}s`n" https://www.okx.com/api/v5/public/time
```

实测：日本节点 7.4 秒（0.2 MB/s）经常超时；美国节点 0.63 秒正常。

## 6. 程序里已经做的容错

- `config.py` 统一创建交易所：自动限频、30 秒超时、自动读 `.env` 里的代理。
- `with_retry`：超时/断线自动重试 2 次（等待 2 秒、4 秒）；403 不重试，重试也没用。
- 某家交易所初始化失败就跳过，单次取价失败只打印一行，程序不停。
