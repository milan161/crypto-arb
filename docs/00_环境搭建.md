# 00 环境搭建（阶段 0）

## 1. 目录约定

```
crypto/                      程序根（不是 git 仓库）
├── src/                     ← git 仓库根，只有这里上传 GitHub
│   ├── core/                业务逻辑：config.py、扫描器等
│   ├── backend/app.py       仪表盘后端（FastAPI）
│   ├── frontend/            仪表盘前端（Vue3 + Vite）
│   ├── requirements.txt
│   ├── .env.example         配置模板
│   └── .gitignore
├── docs/                    说明文档；docs/journal/ 放周记（不上传）
├── data/                    数据（不上传）
├── logs/                    运行日志（不上传）
├── 学习计划/                 计划书
├── .env                     本机密钥、代理、端口（不上传）
├── start.bat / start.ps1    打开开发环境
└── start_dashboard.bat      启动网页仪表盘
```

小伙伴克隆仓库后得到的是 `src/` 的内容，放进自己的 `crypto/src/` 即可。

## 2. 建虚拟环境

```bash
cd D:\Study\ARB\crypto          # PowerShell 写法
# cmd 跨盘符要写成：cd /d D:\Study\ARB\crypto
python -m venv .venv
.venv\Scripts\activate
pip install ccxt python-dotenv pandas
pip freeze > src\requirements.txt
```

PowerShell 提示"禁止运行脚本"时执行一次：
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

小伙伴克隆仓库后：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r src\requirements.txt
copy .env.example .env      # 然后按自己的代理和密钥填写
```

## 3. 代理

国内访问交易所 API 需要代理，在 `.env` 里设置 `HTTPS_PROXY`：

| 软件 | 默认地址 |
|---|---|
| v2rayN | http://127.0.0.1:10808（界面左下角 "本地:[mixed:端口]"） |
| Clash | http://127.0.0.1:7890 |

## 3.1 一键打开开发环境（start.bat）

以后每次开始学习，**双击项目根目录的 `start.bat`** 即可，它会：

1. 进入项目目录
2. 为本窗口设置 `HTTP_PROXY` / `HTTPS_PROXY`（git、pip 等命令行工具也能走代理）
3. 激活 `.venv`（命令行开头出现 `(.venv)`）

代理端口不是 10808 的小伙伴，用记事本打开 `start.ps1` 改端口即可。

## 5. 安全纪律

- 密钥只放 `.env`，代码里不出现明文。
- API Key 只开"读取 + 交易"，永不开提币权限。
- `.env` 已写进 `.gitignore`，提交前用 `git status` 再确认一次。
